## 이용방법

config.json 파일에 토큰과 클라이언트 아이디, 길드 아이디를 넣어주세요<br>
토큰: 디스코드 개발자 포털에서 봇을 만들고 토큰 복사<br>
클라이언트 아이디: 디스코드 개발자 포털에서 봇을 만들고 클라이언트 아이디 복사<br>
길드 아이디: 디스코드에서 개발자 모드 켜고, 서버 우클릭 후 아이디 복사<br>
<br>  
그리고 터미널에 `npm install` 입력 후 엔터<br>
설치가 완료되면 `node .` 입력 후 엔터<br>
봇이 온라인이 됩니다<br>
